# にしかわ

長岡工業高等専門学校（長岡高専）電子制御工学科4年。
セキュリティ・インフラ・バックエンド・データの領域に興味があり、資格取得、データ分析、チーム開発、自宅サーバー運用などに取り組んでいます。

## 自宅サーバー運用（Homelab）

最も力を入れている取り組みです。自分専用の実験環境ではなく、友人など他の利用者も日常的に使う基盤として運用しています。

- Proxmox VEの2ノードクラスタによる仮想化基盤（Raspberry PiをQDeviceとして追加）
- ZFS RAIDZ2（8TB HDD×4）をNAS兼バックアップ基盤として運用
- 主要ゲストに1分間隔のZFSレプリケーションとHAを設定し、ノード停止時の自動復旧を試験済み
- UPSによる停電時の自動正常停止と、復電後の自動復旧を実機で試験済み
- Uptime Kuma / Prometheus / Grafanaで監視し、障害・復旧をDiscordへ自動通知
- バックアップからの隔離復元・ハッシュ値照合・起動確認まで行う復元試験を実施済み
- 利用者に合わせたリソース配分や、遅延・障害発生時のソフトウェア面での対応も自分で行っている

詳細は [homelab](https://github.com/nishikawa5515/homelab) にまとめています。

## プロジェクト

- **[homelab](https://github.com/nishikawa5515/homelab)** — 2ノードクラスタで運用する自宅サーバー基盤の設計・構築・運用と、障害対応・改善の記録
- **[gci_summer2026](https://github.com/nishikawa5515/gci_summer2026)** — 東京大学のデータサイエンス講座「GCI 2026 Summer」の受講記録と、データ分析コンペの提出・改善の過程
- **[dcon2027-yukidaruma](https://github.com/dcon2027-yukidaruma)** — DCON2027参加チーム「ゆきだるま」の組織。屋根の積雪を計測する固定センサ装置「ユキミル」を開発中（開発用リポジトリは非公開）

## 興味分野

- **セキュリティ** — 基本情報技術者・応用情報技術者を取得済み。現在は情報安全確保支援士の取得に向けて勉強中
- **インフラ** — 仮想化基盤の設計・構築から、監視、バックアップ、障害対応までの運用全般
- **バックエンド** — チーム開発や個人の取り組みの中で、サーバー側の実装に興味を持って学習中
- **データ** — GCIでのデータ分析の学習とデータ分析コンペへの参加。データが生成された背景（計測環境や仕組み）まで踏まえて考察することを意識している

## 使用技術

- 仮想化・運用: Proxmox VE / ZFS / Docker / Tailscale
- 監視: Prometheus / Grafana / Uptime Kuma
- データ分析: Python（NumPy / pandas / Matplotlib、機械学習の基礎）

## 経験

- **JR東日本 信号通信技術ユニット（インターンシップ、5日間、新潟）** — 踏切の現地調査、信通機器室での光ケーブル接続やネットワーク設備の見学、信号トレーニングセンターでの踏切設備・転轍機・ATC設備の見学、沿線電話の障害検査の見学、リレーハウスやCTCの見学など、信号通信インフラの現場を広く経験した
- **三菱重工業（インターンシップ、5日間、東京）** — プラント・インフラ分野のDXをテーマに、大学院生中心のチームで提案資料を作成し最終日に発表。関係者へのヒアリングを提案・実施したことで前提が変わり、題材をCO2回収プラントに作り直す経験をした。部内レビューでの指摘を受けて資料を修正した
- **DCON2027 チーム「ゆきだるま」（リーダー）** — 屋根に設置したセンサで積雪の状態を計測し、雪下ろし作業の安全につなげる装置「ユキミル」を開発中。計測基板は Raspberry Pi 4。担当は全体の統合、ハードウェアまわり、先生方や外部機関との調整
