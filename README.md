# にしかわ

長岡工業高等専門学校（長岡高専）電子制御工学科4年。
セキュリティ・インフラ・バックエンド・データの領域に興味があり、資格取得、データ分析、チーム開発、自宅サーバー運用などに取り組んでいます。

## 特に見てほしいもの

- **[homelab](https://github.com/nishikawa5515/homelab)** — Proxmox VEの2ノードクラスタを中心に、HA、監視、バックアップ、復元試験まで行っている自宅サーバー基盤の運用記録です。自分だけでなく友人など他の利用者も使う基盤として運用しています。最も力を入れている取り組みです。
- **[gci_summer2026](https://github.com/nishikawa5515/gci_summer2026)** — 東京大学のデータサイエンス講座「GCI 2026 Summer」の受講記録です。特に見てほしいのは `2_kompe` フォルダで、データ分析コンペで単体モデルからスタッキング／ブレンディングへと手法を変えながら、提出と改善を繰り返した過程（提出ファイル14件とスクリプト一式）が残っています。
- **[dcon2027-yukidaruma（所属チームの組織）](https://github.com/dcon2027-yukidaruma)** — DCON2027にチーム「ゆきだるま」として参加し、屋根の積雪を計測する固定センサ装置「ユキミル」を開発しています。公開リポジトリ `skills` には、チームの運用ルールや進め方をまとめた文書が入っています（開発用リポジトリは非公開です）。

## 興味分野と取り組み

- **セキュリティ** — 基本情報技術者・応用情報技術者を取得済み。現在は情報安全確保支援士の取得に向けて勉強中です。
- **インフラ** — 自宅サーバーを、友人など他の利用者も使う基盤として運用しています（Tailscaleや仮想マシンを使った環境構築・運用）。利用者に合わせたリソース配分や、遅延・障害が発生した際のソフトウェア面での対応も自分で行っています。
- **バックエンド** — チーム開発や個人の取り組みの中で、サーバー側の実装に興味を持って学んでいます。
- **データ** — GCIでのデータ分析の学習や、データ分析コンペへの参加に取り組んできました。統計検定3級、G検定を取得しています。データそのものだけでなく、そのデータが生成された背景（計測環境や仕組み）まで踏まえて考察することを意識しています。

## チーム開発（DCON2027）

- チーム「ゆきだるま」のリーダーを担当しています。
- 開発中の「ユキミル」は、屋根に設置したセンサで積雪の状態を計測し、雪下ろし作業の安全につなげることを目指す装置です。計測基板には Raspberry Pi 4 を使用しています。
